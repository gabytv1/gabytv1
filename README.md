## 🌱 Sobre mí

Soy estudiante de Ingeniería en Computación en la ESPOL y lo que más disfruto de esta carrera es ver cómo una idea se convierte en algo que funciona. Me gusta entender cómo están hechas las cosas por dentro: desde la lógica de un algoritmo hasta la forma en que una página web llega a la pantalla de alguien.

Durante mi formación he trabajado con programación, algoritmos, estructuras de datos, programación orientada a objetos, bases de datos y desarrollo web, y los he aplicado en proyectos universitarios. También he diseñado interfaces y prototipos en Figma, aplicando lo visto en Interacción Humano-Computador. También uso Git y GitHub para llevar el control de versiones. Sigo afianzando JavaScript y CSS, y estoy aprendiendo TypeScript, React y Go.

Estas experiencias me han enseñado a:

- **Descomponer problemas** grandes en partes pequeñas que se pueden resolver una a una.
- **Aprender de forma autónoma**: cuando algo no lo sé, investigo, pruebo, me equivoco y vuelvo a intentar.
- **Trabajar en equipo**, repartiendo tareas, comunicándome con claridad y cuidando que el trabajo de todas las personas encaje.
- **Cuidar el orden**: escribir código legible y dejar un historial de cambios que cuente cómo evolucionó cada proyecto.

### ✨ Lo que me apasiona

- Construir aplicaciones completas, desde la interfaz hasta la base de datos.
- Entender cómo se protege un sistema y por qué fallan las defensas.
- Escribir código claro, ordenado y fácil de mantener.
- Diseñar interfaces pensando en las personas: usabilidad, prototipos y accesibilidad.
- Aprender tecnologías nuevas; ahora mismo, Go, React y TypeScript.
- Colaborar con otras personas y, a futuro, contribuir a proyectos de código abierto.

### 🔎 Qué busco ahora

Estoy buscando **prácticas preprofesionales**, un **primer empleo** o proyectos **freelance** donde pueda aplicar lo que he aprendido, ganar experiencia real y seguir creciendo en el área tecnológica.

## 🎯 Áreas de interés

- 🌐 **Desarrollo full stack:** me interesa trabajar tanto la parte visible de una aplicación (interfaz, diseño, experiencia de uso) como la parte que no se ve (lógica, bases de datos, servidores). Es el área en la que más me quiero formar.
- 🔐 **Ciberseguridad:** me atrae entender cómo se ataca y cómo se protege un sistema, y aprender a desarrollar software seguro desde el principio, no como un añadido al final.
- 🗄️ **Bases de datos:** diseñar tablas bien organizadas, relacionarlas y consultarlas de forma eficiente.
- 🎨 **UX/UI e Interacción Humano-Computador:** diseñar interfaces claras y fáciles de usar, partiendo de las necesidades de las personas. Tengo experiencia utilizando Figma para diseñar interfaces y desarrollar prototipos, y continúo fortaleciendo mis conocimientos para crear diseños usables y accesibles.
- 🧠 **Algoritmos y estructuras de datos:** disfruto pensar en la mejor manera de resolver un problema, no solo en que funcione.
- 🛠️ **Buenas prácticas de ingeniería de software:** control de versiones, código limpio, documentación y trabajo colaborativo.
- 📚 **Aprendizaje continuo:** quiero seguir capacitándome, aprender nuevas tecnologías (ahora Go, React y TypeScript) y, más adelante, estudiar una maestría.

### 🔭 Lo que quiero explorar a futuro

- Crear y consumir **APIs REST**.
- Escribir **pruebas automáticas** para mi código.
- Aprender a **desplegar** aplicaciones y a trabajar con contenedores.
- Profundizar en **seguridad de aplicaciones web**.
