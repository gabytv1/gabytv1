## 🌱 Sobre mí

Soy estudiante de Ingeniería en Computación en la ESPOL y lo que más disfruto de esta carrera es ver cómo una idea se convierte en algo que funciona. Me gusta entender cómo están hechas las cosas por dentro: desde la lógica de un algoritmo hasta la forma en que una página web llega a la pantalla de alguien.

Durante mi formación he trabajado con programación, algoritmos, estructuras de datos, programación orientada a objetos, bases de datos y desarrollo web, y los he aplicado en proyectos universitarios. También he trabajado con Linux y la terminal, y uso Git y GitHub para llevar el control de versiones de mis proyectos.

Estas experiencias me han enseñado a:

- **Descomponer problemas** grandes en partes pequeñas que se pueden resolver una a una.
- **Aprender de forma autónoma**: cuando algo no lo sé, investigo, pruebo, me equivoco y vuelvo a intentar.
- **Trabajar en equipo**, repartiendo tareas, comunicándome con claridad y cuidando que el trabajo de todas las personas encaje.
- **Cuidar el orden**: escribir código legible y dejar un historial de cambios que cuente cómo evolucionó cada proyecto.

### ✨ Lo que me apasiona

- Construir aplicaciones completas, desde la interfaz hasta la base de datos.
- Entender cómo se protege un sistema y por qué fallan las defensas.
- Escribir código claro, ordenado y fácil de mantener.
- Diseñar pensando en quien va a usar el producto.
- Aprender tecnologías nuevas; ahora mismo, el lenguaje Go.
- Colaborar con otras personas y, a futuro, contribuir a proyectos de código abierto.

### 🔎 Qué busco ahora

Estoy buscando **prácticas preprofesionales**, un **primer empleo** o proyectos **freelance** donde pueda aplicar lo que he aprendido, ganar experiencia real y seguir creciendo en el área tecnológica.
